# 智慧监理内部邮件移动端

依据《内部邮件 APP 端产品需求文档 V1.0》和高保真原型实现的无外部依赖移动端 Web App 基线工程。

## 启动

```powershell
npm run dev
```

浏览器访问 `http://127.0.0.1:4173`。

## 工程边界

- `src/app.js`：页面路由、组件渲染与移动端交互。
- `src/services/mail-service.js`：邮件领域接口适配层。当前使用隔离的模拟实现；接入 PC 端后台时只替换该层。
- `src/data/mock-mail-data.js`：演示数据。数量统计作为服务端返回值使用，前端不从列表自行计算。
- `src/components/icons.js`：统一线性图标组件。

## 后端接入约定

真实环境必须由 PC 与 APP 共用的邮件领域服务返回目录统计、列表、详情、权限及人员状态。前端不得根据本地数组重新计算模块数量，也不得绕过发送前人员与权限校验。
